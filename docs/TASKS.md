# TASKS

本文件记录当前阶段状态、交接入口和硬件联调队列。

## 阶段状态

1. 无真设备和硬件联调条件下，可基于业务文档、UI 图、协议文档和离线测试推进的接入工作已收口。
2. 已接入主流程 UI、onboarding/AP 连接边界、Dashboard/Gallery 离线页面导航、控制通道基础层和 `DeviceSession` 命令级契约；不把外部资料当作已验证硬件行为。
3. 不恢复独立 UI 冒烟或截图测试 target；后续 UI/交互微调另行推进。

## 无设备期间

- 只处理发现的离线回归、文档漂移和用户后续明确提出的 UI/交互微调。
- 回放 `Drive Log` 页面按 `UI/回放.png` 完成离线展示；真实文件、时间轴和播放链路仍等硬件联调。
- 不新增依赖真实设备响应的运行时代码路径。

## 硬件恢复后联调队列

- 真设备 `DeviceProtocolEndpoint` 自动发现规则需要硬件或固件侧确认。
- 截图、录像命令模型已接入；页面按钮接线、本地资源保存和真实预览画面仍需真设备或可信设备端模拟器确认。
- 下载任务、播放器、普通设置写操作、危险操作 UI 触发和主动推送状态消费仍需真设备或可信设备端模拟器确认。
- recoverySucceeded 当前直接回到可恢复前态（ready/idle）；真机联调前需确认是否必须重握手，如需则补自动 startProtocolHandshake 闭环。

## 资料缺口

- Settings 的 Privacy Policy、Terms of Service 和真实联系方式仍缺业务正文或真实联系方式，只能保持占位。

## 更新规则

- 做完一轮改动后：
  - 把新的短期目标写回“阶段状态”或“无设备期间”
  - 不记录编译、测试等直观验证信息
  - 如果有用户新指令，优先覆盖旧计划
  - 文档内容保持精简，不重复复述长期事实
