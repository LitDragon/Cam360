# ADR-004: 文档先行开发模式

## 上下文

AI 辅助开发需要项目上下文才能做出正确决策。每次会话重新交代上下文效率低。

## 决策

采用文档先行模式：
- `PROJECT_CONTEXT.md`：长期有效事实（技术基线、目录边界）。
- `TASKS.md`：当前阶段状态和任务队列。
- `CHANGELOG.md`：实际改动记录。
- `docs/specs/`：按能力拆分的规格文档。
- `AGENTS.md`：AI 工作规则和约束。

文档维护在仓库内，与代码同步演进。

## 后果

- 正面：AI 跨会话接手时可快速恢复上下文；新开发者可从文档理解项目。
- 负面：文档有维护成本，需要定期与代码对齐（通过 docs-agent 自动化）。
