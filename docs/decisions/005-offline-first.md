# ADR-005: 离线优先集成策略

## 上下文

真实设备不可用时（无硬件联调条件），需要决定如何推进开发。

## 决策

采用离线优先策略：
- UI 和路由完整实现，但不接入真实设备响应。
- 协议层有完整的编解码和命令模型，但通过 FakeTransport 测试。
- Feature 页面可从 Home、录像页（`RecordingView`）或 Gallery 进入，但保持离线状态（不创建播放器、下载服务或底层连接）。
- 真实设备链路（预览、下载、设置写操作）排队等待硬件联调。

## 备选方案

1. **全等硬件**：开发停滞。
2. **Mock 一切**：UI 和逻辑可能与真实设备行为不符，后续返工成本高。

## 后果

- 正面：UI 和架构可先行验证；协议层有测试覆盖。
- 负面：部分功能（预览、下载）只能做占位，真实行为需硬件确认后才能验证。
